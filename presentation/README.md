# Финальная презентация

`Falcon_Tech_Vehicle_ReID.pptx` — готовая сдаваемая версия из 18 слайдов,
собранная на официальном шаблоне ЛЦТ 2026.

В презентации уже указаны команда, участники, контакты и ссылка на репозиторий.
Она описывает задачу, путь оператора, архитектуру, четыре группы сигналов,
качество, отказ, производительность, ошибки, бизнес-ценность и план развития.
Локальные измерения явно отделены от ещё не выполненного замера на стенде
организаторов. На performance-слайде сохранены ссылки на первичные источники.

Перед отправкой достаточно открыть файл в PowerPoint и проверить, что шрифты и
изображения отображаются на конкретном компьютере. Генератор
`scripts/build_presentation.py` является прежней служебной версией и не должен
использоваться для пересборки финального файла: он перезапишет актуальную
презентацию упрощённым вариантом.

Пакеты из `requirements-presentation.txt` нужны только старому генератору и не
входят в release Docker, не участвуют в inference и не влияют на метрики.

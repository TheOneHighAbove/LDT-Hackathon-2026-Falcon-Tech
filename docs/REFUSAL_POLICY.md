# Обоснование open-set отказа

## Что предсказывает policy

После завершения retrieval и reranking система уже имеет конкретный top-1.
Отдельная логистическая модель оценивает вероятность того, что именно этот
кандидат корректен. Если вероятность ниже порога, query не записывается в
`candidates.csv`; это и есть отказ.

Policy не меняет `submission.csv` и не влияет на mAP@10. Она также не видит
другие test query, camera ID, порядок CSV или разметку теста.

## Признаки

Используются восемь сигналов, доступных для одного текущего query и статической
gallery:

1. итоговый score top-1;
2. разрыв top-1/top-2;
3. разрыв top-1 относительно top-5;
4. cosine выбранного кандидата;
5. его cosine-разрыв top-1/top-2;
6. его cosine-разрыв относительно top-5;
7. локальная плотность выбранного gallery-элемента;
8. изолированность выбранного gallery-элемента.

## Протокол калибровки

- 308 validation identity;
- один query на identity;
- 246 известных и 62 неизвестных query в каждом эпизоде;
- фактическая доля unknown — 20.13%, ближайшее дискретное значение к 20%;
- gallery — 750 изображений только известных identity;
- у каждого известного query есть cross-camera positive;
- пересечение query/gallery по изображениям и попадание unknown ID в gallery
  проверяются программно;
- пять tune seed используются для group-OOF, обучения модели и выбора порога;
- пять confirmation seed не участвуют в подборе.

## Почему порог равен 0.630795

На tune OOF перебираются наблюдаемые вероятности. Допускаются только точки с
`TNR >= 0.94`; среди них выбирается максимальный candidate F1. Полученная точка
имеет порог `0.6307946113`. Ограничение по TNR защищает от политики, которая
формально повышает recall, но принимает слишком много неизвестных машин.

## Locked confirmation

| Метрика | Новая policy | Предыдущая policy на тех же эпизодах |
|---|---:|---:|
| F1 | 0.836127 | 0.835478 |
| TNR | 0.951613 | 0.925806 |
| Precision | 0.978214 | 0.960888 |
| Recall | 0.730081 | 0.739024 |
| `0.7 × F1 + 0.3 × TNR` | **0.870773** | 0.862576 |

Новая точка сознательно отдаёт около 0.9 п.п. recall за 2.6 п.п. TNR. С учётом
официальной формулы итоговый компонент растёт на 0.008196. На публичном test
policy принимает 975 из 1110 query и отказывает для 135; это не является
оценкой скрытой точности, поскольку test labels неизвестны.

Полные коэффициенты, OOF folds, confusion matrix и протоколы seeds находятся в
`outputs/score_optimized_speed/refusal_calibration.json`.

## Риски

- Закрытый test может отличаться по типам неизвестных автомобилей.
- Вероятности логистической модели нельзя трактовать как идеально
  откалиброванные вероятности на любом домене.
- Порог следует менять только через повторяемую tune/confirmation процедуру,
  а не по числу отказов на test.
